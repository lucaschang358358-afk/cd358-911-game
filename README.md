# 911 緊急調度員 2.5D v3 — 無敵 CD-358 專屬版 (1,000 關)

專為 **無敵 Besta CD-358** 打造的 2.5D 輕量不卡頓 911 緊急調度模擬遊戲，**單一 `.exe` 內建全部 1,000 個繁體中文獨立劇本**（無需額外資料檔）。

## 特色重點
1. **1,000 關獨立劇本 ＋ 分塊壓縮隨用隨解**：將 1,000 關分成 20 個壓縮區塊（每塊 50 關）直接編進 `.exe`，執行時只佔 40 KB 靜態 RAM 緩衝，完全不爆記憶體、不卡頓。
2. **真 50/50 隨機選項位置 ＋ 錯誤懲罰**：每輪對話都有 1 個專業正確選項與 1 個荒謬／錯誤選項，`[1]` / `[2]` 位置完全隨機洗牌；選錯會扣星並遭吐槽，2 題全錯或派錯車會直接任務失敗。
3. **2.5D 透視立體畫面 ＋ 事件驅動省電**：待機調度室雷達與閃燈、911 電腦螢幕對話框、以及過關 2.5D 立體警車／救護車／消防車出勤動畫全採高速整數掃描線繪製；對話選擇時完全靜止不重繪，按鍵零延遲。
4. **純實體按鍵操作（完全關閉觸控）**：專為無觸控環境設計，自動適配 320×240 / 480×320 / 800×480 與 RGB565 / XRGB8888。

## GitHub Actions 編譯與安裝
1. 將本資料夾所有檔案上傳至你的 GitHub 倉庫（含 `.github/workflows/build-muteki.yml`）。
2. 到 **Actions** 頁籤等待 **Build CD-358 911 Emergency 2.5D** 完成。
3. 下載 Artifacts 的 **`cd358-911-muteki-exe`**，裡面包含：
   - `cd358-911-arm7.exe`（通用高相容版，建議優先使用）
   - `cd358-911-arm9.exe`（ARM9 最佳化版）
4. 將其中一支 `.exe` 直接複製到 CD-358 即可遊玩（存檔會自動存於 `C:\cd358_911_v3.sav`）。

## 純實體按鍵操作
| 按鍵 | 功能 |
| :--- | :--- |
| `Enter` / `Space` | 接聽來電 / 確認選項 / 進入下一關 |
| `1` / `2`（或 `↑` `↓` + `Enter`） | 選擇 911 對話回覆（位置每輪隨機！） |
| `1`～`4`（或方向鍵 + `Enter`） | 派遣：`1` 警車、`2` 救護車、`3` 消防車、`4` 掛斷 |
| `G` | 跳關（直接敲數字 1～1000 或方向鍵微調） |
| `T` | 切換日／夜護眼配色 |
| `R` | 重玩本關 |
| `H` | 查看按鍵說明、職級統計與實機偵測資訊 |
| `ESC` | 返回待機畫面 / 待機畫面按 `ESC` 顯示離開確認 |
